# Student Management System

## 📌 Project Overview

The Student Management System is a simple web-based application developed to manage student information efficiently.

The system allows users to add, view, edit, and delete student records using a simple and user-friendly interface.

## 🎯 Objectives

- To maintain student records digitally.
- To add new student details.
- To view existing student details.
- To update student information.
- To delete student records.
- To perform basic CRUD operations.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Django
- SQLite
- Visual Studio Code

 Main Modules
 1. Add Student
Allows the user to enter and save new student details.

 2. View Students
Displays the list of available student records.

 3. Edit Student
Allows the user to modify existing student information.

 4. Delete Student
Allows the user to remove a student record.

 CRUD Operations

| Operation | Description |
|-----------|-------------|
| Create | Add a new student |
| Read | View student details |
| Update | Edit student details |
| Delete | Delete a student record |

 Database

The project uses SQLite database to store student information.

 How to Run

1. Install Python.
2. Install Django.
3. Open the project folder.
4. Run the Django development server.
5. Open the application in a web browser.
